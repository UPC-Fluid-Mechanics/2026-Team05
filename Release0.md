## Project Title

Design of an Axial Fan for a car radiatator

## Project description

The objective of this project is to design an axial fan for a car radiator. We will then evaluate its perfomances using CFD.

## Applications
- Automotive engine cooling
- Heat exchangers
- Heating, ventilation and air conditioning (HVAC)

## Examples of existing fans

## Estimated power consumption

We can estimate the power using the expression $P_air = Q\delta_p. If we consider Q = 1m^3/s and delta_p = 1100 Pa, P_air = 1100W.
